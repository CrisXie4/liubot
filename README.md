## ✨ 核心功能

### 🛡️ 群管理与自动审核
- **自动审核引擎**：关键词权重 + TF-IDF/朴素贝叶斯双引擎，四阶段成长（冷启动 → 学习 → 进阶 → 成熟），自动识别并撤回广告/违规，高置信度自动拉黑
- **图片审核（Vision）**：对所有图片/GIF/商城表情自动违规识别，GIF 抽 3 关键帧分别审，OCR 由 vision 模型自带，同图 24h 只审一次
- **手动违规管理**：主人回复消息 + `@Bot 违规` 一键记录并撤回，黑名单全局/分群生效
- **新人验证**：加群自动出题验证，支持网站认证（Cloudflare Turnstile）模式、免验证白名单
- **昵称/名片巡检**：违规昵称自动检测，24h 去重不骚扰

### 💬 AI 群聊（真人感）
- **人设系统**：自定义名字/性格/说话风格，支持完全自定义 soul 提示词
- **心情系统**：心情数值实时波动（被夸开心/被骂烦躁/被忽视失落），心情直接改变说话方式（烦躁时单字敷衍是合法的）
- **主动社交**：会主动搭话、心里"悬着的事"、记挂着要跟进问你的事（"你上次说的那个后来怎么样了"），被连续忽视会知趣地退避
- **表情包**：自动收藏群里的表情/动图，按情绪和语境挑选发送，也支持 QQ 大黄脸快捷码
- **消息理解**：图片视觉理解、合并转发消息展开阅读、引用消息上下文、语音转文字、网页浏览（web_open/web_click 三件套）
- **引用回复**：像真人一样引用你的消息回复，长文自动转合并转发
- **AI 语音**：QQ 官方 AI 音色开口说话（NapCat AI 电台）
- **群互动游戏**：掷骰子、猜拳、点歌卡片
- **表情回应感知**：你给 Bot 的消息贴了什么表情，它下次说话知道
- **新闻分享**：AI 自主上网冲浪学新东西，挑有意思的随口分享给群友（配图视觉校验防图文不符，已分享过的不重复）
- **说话像人**：水位窗上下文、气泡节奏随机化、长度跟话题走、深夜打字变慢

### 🌐 中转站数据库（可选）
配置 `RELAY_DB_URL` 后，AI 可直接用 SQL 查询 LLM 中转站的用量数据：
- 群里直接问"谁用的最多""这个月用了多少 tokens"，AI 自己写查询并以口语回答
- 只读事务强制只读，密码/密钥列自动打码；修改操作仅限主人

### ⚙️ Web 控制面板
仪表盘 / 违规记录 / 黑名单 / 审核样本训练 / AI 人设 / 模型设置（多渠道注入、思考强度）/ AI 记忆 / 定时任务 / 加群验证，全可视化操作

## 快速开始

### 1. 安装 NapCatQQ

下载并运行 [NapCatQQ](https://github.com/NapNeko/NapCatQQ/releases)，登录 Bot QQ 号，确保 WebSocket 服务已开启（默认端口 `3001`）。

> **前提**：Bot 账号需要是**群管理员**才能撤回消息。

### 2. 配置 Python Bot

```bash
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env，必填: BOT_QQ, OWNER_QQ,（可选）LLM_API_KEY
```

### 3. 启动

```bash
python main.py
```

启动后：
- Bot 连接 NapCat 并开始监听 QQ 消息
- Web 控制面板：**http://127.0.0.1:8090**

### 4. 联网能力（可选）

- 部署 [SearXNG](https://docs.searxng.org/)（默认 `http://127.0.0.1:8080`，可用 `.env` 的 `SEARXNG_URL` 覆盖）即可解锁 AI 自主学习/新闻分享/网页搜索
- `.env` 里配置 `RELAY_DB_URL` 解锁中转站数据查询（AI 只读，主人可写）

## 自动审核工作原理

### 阶段 1：冷启动（0-10 条违规）
纯关键词匹配，使用内置违禁词库

### 阶段 2：学习中（10-30 条）
关键词权重从违规记录中动态学习，匹配更精准

### 阶段 3：进阶（30-80 条）
关键词引擎 + ML 分类器（TF-IDF + 朴素贝叶斯）混合使用

### 阶段 4：成熟（80+ 条）
双引擎协同工作，自动审核精度显著提升

**评分公式**：`置信度 = Σ(关键词权重 × 匹配次数) × 归一化因子`

- 置信度 ≥ 0.9 → 自动撤回
- 置信度 ≥ 阈值（动态调整，0.85 → 0.25） → 自动撤回
- 置信度 ≥ 0.95 → 自动撤回 + 自动加入黑名单

## 常见问题

**Q: 撤回失败？**
A: Bot 需要是群管理员。超过 2 分钟的消息无法撤回。

**Q: AI 聊天不回复？**
A: 检查 `.env` 中 `LLM_API_KEY` 是否正确。

**Q: 自动审核误判太多？**
A: 在 Web UI 中关闭自动审核，手动标记更多违规来训练模型，或提高阈值。

**Q: 如何后台运行？**
A: Windows 用 `nssm`，Linux 用 `systemd` 或 `screen`。
