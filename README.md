# QQ 智能群管机器人 v2.0

基于 **NapCatQQ + Python** 的全功能 QQ 群管理机器人，配备 **Web 控制面板**。

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🚫 **手动违规管理** | 主人回复消息 + `@Bot 违规` 即可记录并撤回 |
| 🤖 **自动审核引擎** | 关键词权重 + TF-IDF/朴素贝叶斯双引擎，自动识别并撤回广告/违规 |
| 📊 **智能学习** | 从违规记录中持续学习，训练越多越精准 |
| ⛔ **黑名单管理** | 支持全局/分群黑名单，自动拦截 |
| 💬 **AI 聊天** | 接入大模型，可配置人设性格 |
| 🧠 **AI 长期记忆** | 记住群友画像、对话摘要、知识碎片 |
| 💡 **智能主动聊天** | LLM 驱动，根据对话内容+记忆主动加入讨论 |
| ⚙️ **模型设置面板** | Web UI 配置 API 端点、模型、Temperature、思考强度 |
| 🎭 **人设配置** | 自定义名称、性格、说话风格、主动搭话 |
| ⏰ **定时消息** | 支持 cron 和 interval 两种模式 |
| 🌐 **Web 控制面板** | 仪表盘、违规记录、黑名单、自动审核、人设、定时消息全可视化管理 |

## 快速开始

### 1. 安装 NapCatQQ

下载并运行 [NapCatQQ](https://github.com/NapNeko/NapCatQQ/releases)，登录 Bot QQ 号，确保 WebSocket 服务已开启（默认端口 `3001`）。

> **前提**：Bot 账号需要是**群管理员**才能撤回消息。

### 2. 配置 Python Bot

```bash
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env，必填: BOT_QQ, OWNER_QQ, （可选）LLM_API_KEY
```

### 3. 启动

```bash
python main.py
```

启动后：
- Bot 连接 NapCat 并开始监听 QQ 消息
- Web 控制面板：**http://127.0.0.1:8090**

## 自动审核工作原理

### 阶段 1：冷启动（0-10 条违规）
纯关键词匹配，使用内置违禁词库

### 阶段 2：学习中（10-30 条）
关键词权重从违规记录中动态学习，匹配更精准

### 阶段 3：进阶（30-80 条）
关键词引擎 + ML 分类器（TF-IDF + 朴素贝叶斯）混合使用

### 阶段 4：成熟（80+ 条）
双引擎协同工作，自动审核精度显著提升

**评分公式**：`置信度 = Σ(关键词权重 × 匹配次数) × 归一化因子`

- 置信度 ≥ 0.9 → 自动撤回
- 置信度 ≥ 阈值（动态调整，0.85 → 0.25） → 自动撤回
- 置信度 ≥ 0.95 → 自动撤回 + 自动加入黑名单

## 图片审核（Vision）

机器人会对群里的**所有图片、GIF 动图、商城表情**自动做违规识别，用专门的 vision 模型（默认 `minimax-m3-free`）：

- 识别图片里的广告/色情/赌博/诈骗内容
- 自动读出图片里的文字（OCR 能力由 Vision 模型自带，无需装 Tesseract）
- GIF 自动抽取首/中/末 3 个关键帧分别识别
- 同一张图 24 小时内只审一次（缓存）

主模型 `gemini-3.5-flash-free` 通过此 API 网关**不支持 vision**（API 收图但模型忽略），所以图片类任务一律走 vision 模型。在 `.env` 里配置：

```
LLM_VISION_MODEL=minimax-m3-free   # 必须是支持 vision 的模型
```

## 常见问题

**Q: 撤回失败？**
A: Bot 需要是群管理员。超过 2 分钟的消息无法撤回。

**Q: AI 聊天不回复？**
A: 检查 `.env` 中 `LLM_API_KEY` 是否正确。

**Q: 自动审核误判太多？**
A: 在 Web UI 中关闭自动审核，手动标记更多违规来训练模型，或提高阈值。

**Q: 如何后台运行？**
A: Windows 用 `nssm`，Linux 用 `systemd` 或 `screen`。
